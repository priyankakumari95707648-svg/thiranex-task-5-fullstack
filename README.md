# Thiranex Task 5 — Full-Stack Deployment & Project Architecture

## ShopEase
A responsive e-commerce product catalog built with HTML5, CSS3 and Vanilla JavaScript.

### Features
- Modular JavaScript architecture
- Client-side hash routing
- Product catalog and product detail pages
- Search and category filtering
- Shopping cart with quantity controls
- `localStorage` persistence
- Responsive mobile-first layout
- Accessible labels and semantic HTML
- Lightweight static deployment
- No external dependencies

### Project structure
```text
thiranex-task-5-fullstack/
├── index.html
├── css/
│   └── style.css
├── js/
│   ├── app.js
│   ├── data.js
│   └── store.js
├── assets/
└── README.md
```

### Run locally
Open `index.html` in a browser, or use VS Code Live Server.

### Deploy
Upload this folder to GitHub, then import the repository into Vercel or Netlify. Use the repository root as the project root; no build command is required.

### Submission
Submit the deployed public URL if the portal asks for a live URL. If it asks for GitHub, submit the repository URL.
